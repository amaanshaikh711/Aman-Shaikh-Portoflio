# Aman Shaikh — 3D Developer Portfolio

A highly interactive, professional developer portfolio built to showcase real-world projects, machine learning infrastructure, and frontend engineering expertise.

## 🚀 Overview

This portfolio serves as a central hub for my professional identity, demonstrating my focus on bridging the gap between complex backend architectures (like Python/Flask and AI pipelines) and breathtaking user interfaces. I’ve incorporated advanced web technologies to ensure a scalable, immersive, and fully responsive experience.

## ✨ Features & Enhancements

Through extensive customization, this application has been optimized to include:

- **Immersive 3D Render Models:** Configured local React Three Fiber canvases with custom `SmartOrbitControls` for ultra-smooth physical mapping and rotational recovery.
- **Dynamic Projects Layout:** A tailored grid-focused projects module featuring my work in Real-Time NLP, Sales Prediction Dashboards, and full-stack eCommerce architectures.
- **Glassmorphic UI Systems:** Re-architectured the global component layers to rely on premium blurry gradients, floating headers, and dynamic CSS borders.
- **Professional Timeline:** Reconstructed the experience and skills sections into high-fidelity layout blocks with custom interactivity.
- **Fluid Responsiveness:** Engineered viewport-tailored grids spanning everything from ultra-wide 4K down to compact mobile setups seamlessly using Tailwind CSS.

## 🛠️ Core Tech Stack

- **Frameworks:** React.js, Next.js, Vite
- **3D Graphics:** Three.js, React Three Fiber, Framer Motion
- **Styling:** Tailwind CSS, Vanilla CSS
- **Backend / AI (Referenced Work):** Python, Flask, NLP, Scikit-Learn
